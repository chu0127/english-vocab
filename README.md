# 每日英文生字 · English Vocab

每日英文生字溫習 app（廣東話介面）：今日溫習（間隔重複 SRS）、閃卡、默書／選擇題測驗、字庫、進度統計。

👉 **App：https://chu0127.github.io/english-vocab/**

- `index.html` — 建置好嘅單一檔案 app（所有 CSS / JS / 錄音都內嵌）
- `words.json` — 生字庫
- `src/` — 原始碼；`tools/` — 錄音、建置、測試、發佈腳本
- 加新課：見 [HOW-TO-ADD-WORDS.md](HOW-TO-ADD-WORDS.md)

錄音：Microsoft Edge TTS（en-GB-SoniaNeural）；冇錄音嘅字用瀏覽器內置語音。
